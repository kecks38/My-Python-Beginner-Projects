
# Консольный калькулятор на Python

Мой первый учебный проект: консольный калькулятор для двух чисел.

## Что умеет

- Принимает два числа (целые и дробные, в том числе отрицательные).
- Предлагает выбрать операцию: сложение, разность, умножение, деление.
- Выводит результат.
- Если ввести не число или выбрать несуществующую операцию, выводит сообщение об ошибке и завершает работу.

## Как запустить

1. Установите Python 3.
2. Запустите в терминале:

```
python lite_python_calculator.py
```

## Тестирование

Для калькулятора вручную составлен набор тест-кейсов: [test_cases.xlsx](test_cases.xlsx). В нём 11 проверок: обычные операции, отрицательные и дробные числа, ввод букв и пустого значения, деление на ноль, несуществующая операция.

## Известные проблемы

По результатам тестирования найдены дефекты, которые пока не исправлены:

1. После сообщения о делении на ноль выводится лишняя строка `Результат деления: None`.
2. При выборе несуществующей операции сообщение об ошибке не подсказывает, какие пункты доступны.
3. Результат деления выводится без округления (например, `3.3333333333333335`).
